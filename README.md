# 弹幕猫娘 (neko_danmaku)

把宿主聊天搬到游戏/窗口画面：主人说的话、YUI 的回应，以弹幕形式从目标画面飘过。
玩游戏不用切出聊天窗——猫娘的陪伴直接浮在画面上。

## 特性

- **宿主聊天 → 弹幕**：默认走宿主 conversations 通道，主人说话、YUI 回应、
  **猫娘主动搭话**全部逐条上屏
- **OBS 式目标**：可选显示器或某个窗口/游戏程序，浮层自动贴合窗口大小，
  窗口移动/缩放/全屏切换跟着走（M1 前台/显示器，M2 完整列表）
- **鼠标穿透**：默认穿透不挡操作，热键 `Ctrl+Alt+D` 切换交互（点击弹幕暂停/继续）
- **干净弹幕**：实心字 + 均匀描边，无背景块（可选极淡/柔和底条）
- **样式系统**：多预设（clean/master/neko/champagne/softbar/pink/mix 彩色混合），
  字体/字号/透明度/颜色/速度全部热调，即时生效
- **按时间自然滚动**：弹幕跟随聊天时间一条条进入，突发也不叠车；
  同轨道碰撞预测，速度再快也不重叠
- **括号演出注释源头剔除**：`（猫耳抖了抖）` 这类旁白不会上屏
- **零第三方安装**：自带 PySide6（vendor 打包），宿主 py311 即装即用

## 控制台

面板已重构为贴近宿主的液态玻璃控制台，默认白色主题，可切换到夜间主题；
选择会保存在浏览器本地。左侧按“总览 / 弹幕目标 / 外观与排版 / 聊天来源 / 诊断”
组织全部功能，桌面和窄屏分别使用侧栏与底部导航。

- 总览直接显示浮层状态、实际数据源、当前目标、可跟随窗口和实时样式预览。
- 外观页使用独立预览画布，字体、描边、阴影、辉光、底条和排版修改后统一保存。
- 目标页支持搜索进程，显示器与窗口均为键盘可操作的真实按钮。
- 面板轮询自动防重入；编辑中的样式不会被后台状态刷新覆盖。
- 无效配置会在宿主端和浮层端同时限幅，避免异常字符串进入绘制路径。

- 面板新增「数据源 / SDK 间隔」控件 + 状态显示实际生效源（含回退提示）
- 新增插件入口 `set_data_source`：面板 / agent / 聊天都可切换并即时生效

### 0.2.0 — 显示布局与美观度

- **自动折行**：长句按屏宽 62% 折行、最多 N 行（默认 3），超出加省略号，不再横穿整屏
- **字号自适应**：按浮层宽度相对 1920 缩放（0.72~1.55 倍），小窗口/大屏都清晰
- **紧凑轨道排布**：每条轨道按自身最高条目占位，多行弹幕不会压到下一轨，单行间距不浪费
- **入场淡入 / 左缘淡出**：130ms 淡入、最后 150px 淡出，出现与消失更柔和
- **亚像素绘制**：浮点坐标 + 平滑变换，低速滚动不再一格一格跳
- **行距 / 字距可调**：默认行距 1.12，长句更透气
- **同屏条数上限**：默认 42 条，突发不糊屏，超出排队
- **面板新增「显示」卡片**：弹幕区(上/中/下) + 偏移、同屏上限、淡入时长、自动折行开关 + 行数、字号自适应、行距、字距；预览同步折行效果
- 浮层状态接口新增 `area_offset` / `tracks`，面板可回显实际轨道数

### 0.2.0 — 角色差异化（像弹幕，不像字幕）

- **主人与猫娘样式彻底分开**：主人 `master`（暖白 `#fff6e5` + 深描边 + 轻阴影，无底条）；
  猫娘 `mix`（随机彩色 + 半透明圆角气泡），不会再有"两边都是白字黑边"的观感
- **修掉样式串味**：角色预设改为**隔离合并**（以 clean 为底叠预设），
  不再继承全局样式残留——之前全局切过 mix 后，主人的条目也会被塞彩色池
- **弹幕感抖动**：每条速度 ×0.86~1.14、字号 ±1、垂直位置 ±4px，不再整整齐齐排队
- **默认更"弹幕"**：字号 34→30、速度 150→190
- **猫娘彩色池去掉纯白**：保证猫娘永远不会和主人同款白字
- **面板「角色样式」下拉**：主人 / 猫娘分别选预设，即时生效并持久化
  （新入口 `set_role_style`）

### 0.2.0 — 全屏游戏绑定修复

- **修掉全屏误判遮挡**：无边框全屏游戏时，z-order 上其它置顶/透明小窗会被判定成"遮挡"，
  导致浮层被隐藏、弹幕全部丢弃。现在：目标铺满所在显示器且在前台 → 不判遮挡
- **绑定重试**：按进程/窗口绑定但目标窗口还没就绪（游戏启动中、切全屏重建窗口）时，
  记住绑定意图并在跟随循环里持续重试，窗口就绪自动接上（原来会永久空目标、静默丢弃弹幕）
- **诊断可见**：浮层状态新增 `obscured` / `target_hwnd` / `pending_target` / `dropped`；
  面板状态栏显示「⚠ 目标被遮挡，弹幕已暂停」/「等待目标窗口就绪…」/「未绑定目标」；
  插件日志对"浮层未接收弹幕"按原因节流告警
- 全屏目标在切换后自动 `raise()` + 保持置顶

> ⚠ 独占全屏（Exclusive Fullscreen）由游戏直接接管显示输出，任何浮层都盖不上去。
> 需要把游戏显示模式改成「无边框全屏 / 窗口全屏（Borderless）」。

## 安装

1. 将插件放入 N.E.K.O 插件目录并启用（首次启动自动拉起浮层）
2. 热键：`Ctrl+Alt+D` 穿透⇄交互 / `Ctrl+Alt+F5` 自检弹幕 / `Ctrl+Alt+X` 退出浮层

## 配置

编辑 `plugin.toml` 的 `[neko_danmaku]` 段：

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `data_source` | `sdk` | 数据源：`sdk`（推荐，宿主 conversations 通道，**含 AI 主动搭话**）`time_index`（文件名时间索引）`recent_file`（recent.json） |
| `recent_path` | 自动探测 | 指定 recent.json 路径（留空自动找） |
| `db_path` | 自动探测 | 指定 time_indexed.db 路径（留空自动找） |
| `poll_interval_s` | `0.8` | 文件源轮询间隔 / SDK 间隔上限 |
| `sdk_poll_interval_s` | `0.3` | SDK 拉取间隔（拉取式通道，0.2~0.3 秒接近实时） |
| `overlay_port` | `48777` | 浮层本地端口 |
| `auto_start_overlay` | `true` | 启动是否自动拉起浮层 |
| `role_preset` | human=master / ai=mix | 主人/YUI 各自样式预设 |

### 数据源说明

- **`sdk`（默认）**：走 `ctx.bus.conversations`，宿主每回合都会把 `user_message` /
  `assistant_message` / **`proactive_reply`（猫娘主动搭话）** 写入该通道，
  这是唯一能拿到"自主发言"的来源。该通道是**拉取式**（不支持 watch 推送），
  所以按 `sdk_poll_interval_s` 增量轮询，按记录到达时间做游标 + event_id 去重。
  宿主不提供该通道（旧版/用户插件关闭）时自动回退 `time_index`。
- **`time_index` / `recent_file`**：文件源，只有"用户回合"，拿不到主动搭话；
  作为主源时会额外挂一条 SDK 补源，**只推 `proactive_reply`**（避免与文件源重复上屏）。

浮层样式可用 `POST /config` 热调（面板 M2 提供 UI）。

## 开发

```
neko_danmaku/
├── core/      # runtime 编排 / config / recent_reader / cleaner
├── overlay/   # Qt 浮层子进程 (自包含, 只依赖 PySide6)
└── vendor/    # PySide6 (cp310-abi3 wheel 解包)
```

- 本地验证：`python core/cleaner.py`（自测）；浮层
  `PYTHONPATH=vendor python overlay/app.py`
- 回归测试：`python -m pytest -q tests`
- 面板脚本语法：`node --check static/panel.js`
- vendor 更新：PySide6 wheel 解包至 vendor/（cp310-abi3 兼容宿主 py311）
