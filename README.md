# 弹幕猫娘

> 把 N.E.K.O 的聊天变成画面上的弹幕，让猫娘真正陪你玩游戏。

弹幕猫娘会把主人发言、猫娘回复和主动搭话投送到游戏窗口或显示器上方。
不切聊天窗、不打断游戏操作，鼠标默认穿透，窗口移动和全屏切换时自动跟随。

## 核心体验

| 能力 | 使用体验 |
|---|---|
| 聊天上屏 | 主人与猫娘的每一条对话按真实聊天节奏进入弹幕轨道 |
| 主动搭话 | 读取宿主 conversations 通道，猫娘主动发言也能显示 |
| 精准跟随 | 可绑定显示器、游戏进程或指定窗口，自动贴合客户区 |
| 鼠标穿透 | 默认不挡游戏操作，热键可临时切换为交互状态 |
| 独立样式 | 主人与猫娘分别设置颜色、底条、阴影和角色预设 |
| 自然排版 | 长句自动折行、字号跟随屏宽、轨道避碰、突发不重叠 |
| 液态玻璃控制台 | 默认浅色，可切换夜间主题，桌面与窄屏均有独立布局 |

## 控制台

面板采用 N.E.K.O 风格的液态玻璃视觉，按任务划分为五个工作区：

- **总览**：浮层连接、实际数据源、当前目标和实时弹幕预览。
- **弹幕目标**：显示器列表、进程搜索和窗口绑定。
- **外观与排版**：字体、描边、阴影、辉光、底条、折行与速度。
- **聊天来源**：SDK conversations、文件索引和旧版数据源切换。
- **诊断与工具**：链路自检、目标状态、回收计数和技术信息。

主题默认为白色，用户切换后会保存在浏览器本地。编辑中的样式不会被后台状态刷新覆盖。

## 安装

1. 将 `neko_danmaku` 安装到 N.E.K.O 插件目录并启用。
2. 插件首次启动会自动拉起透明弹幕浮层。
3. 打开控制台，在“弹幕目标”中选择游戏窗口或显示器。
4. 回到聊天继续和猫娘说话，弹幕会出现在目标画面。

已内置 PySide6，无需额外安装 Python 图形依赖。

## 快速上手

打开面板后：

1. **选择目标**：推荐绑定游戏进程，窗口重建或切换全屏时会继续跟随。
2. **选择预设**：主人推荐 `master`，猫娘推荐 `mix` 或 `neko`。
3. **运行自检**：在“诊断与工具”中发送测试弹幕，确认目标和浮层链路。
4. **微调外观**：修改后点击“保存外观”，所有参数会即时同步到浮层。

游戏内热键：

| 热键 | 功能 |
|---|---|
| `Ctrl+Alt+D` | 鼠标穿透 / 交互模式切换 |
| `Ctrl+Alt+F5` | 推送一条演示弹幕 |
| `Ctrl+Alt+X` | 退出弹幕浮层 |

> 独占全屏会被游戏直接接管显示输出，请在游戏内使用“无边框全屏 / 窗口全屏”。

## 聊天数据源

- **SDK conversations（推荐）**：同时覆盖主人发言、猫娘回复和 `proactive_reply` 主动搭话。
- **time_index**：读取宿主对话时间索引，只包含用户回合。
- **recent.json**：旧版兼容来源；使用时会额外接入 SDK 补源以保留主动搭话。

面板会显示配置来源和实际生效来源。宿主 conversations 通道不可用时会自动回退，
不会让弹幕直接失效。

## 稳定性与隐私

- 相同对话通过到达时间游标与 `event_id` 去重，不重复上屏。
- 首启跳过历史存量，只播放启动后的新聊天。
- 后台轮询防重入，窗口不可见时暂停定时刷新。
- 宿主配置和浮层绘制参数均做边界校验，异常值不会进入渲染路径。
- 弹幕浮层只监听本机 `127.0.0.1` HTTP 接口。
- 对话与配置保留在本机，不上传到第三方服务。

## 开发

```text
neko_danmaku/
├─ core/      数据源编排、配置、文本清洗
├─ overlay/   Qt 透明浮层与 Win32 窗口跟随
├─ sources/   conversations、SQLite、recent.json 数据源
├─ static/    液态玻璃控制台
├─ tests/     UI、配置、数据源与绘制回归测试
└─ vendor/    随插件分发的 PySide6
```

```powershell
python -m pytest -q tests
ruff check .
node --check static/panel.js
```

本地运行浮层：

```powershell
$env:PYTHONPATH="vendor;overlay"
python overlay/app.py
```
