# 弹幕猫娘使用指南

把 N.E.K.O 的聊天投送到游戏或窗口上方，不影响鼠标操作。

## 快速开始

1. 启用插件，等待弹幕浮层自动启动。
2. 打开面板，在“弹幕目标”中选择游戏窗口或显示器。
3. 在“外观与排版”中调整样式并保存。
4. 回到聊天继续对话，主人和猫娘的发言会出现在目标画面。

推荐绑定游戏进程，窗口重建或切换无边框全屏后仍能继续跟随。

## 常用功能

- **目标**：支持显示器、游戏进程和普通窗口，可搜索进程标题。
- **外观**：字体、字号、描边、阴影、辉光、底条、折行和速度。
- **角色样式**：主人推荐 `master`，猫娘推荐 `mix` 或 `neko`。
- **聊天来源**：默认使用 SDK conversations，可读取猫娘主动搭话。
- **诊断**：发送两条测试弹幕，检查目标绑定和完整推送链路。

## 热键

| 热键 | 功能 |
|---|---|
| `Ctrl+Alt+D` | 鼠标穿透 / 交互模式 |
| `Ctrl+Alt+F5` | 推送演示弹幕 |
| `Ctrl+Alt+X` | 退出浮层 |

## 配置位置

配置统一保存在插件 `data/config/`：

- `general.json`：插件总开关。
- `source.json`：聊天来源和拉取间隔。
- `overlay.json`：端口、自启和角色预设。
- `overlay_style.json`：弹幕外观与排版。
- `ui.json`：面板主题。

桥接游标等运行状态保存在 `data/state/`，不会进入发布包。

## 常见问题

- **没有弹幕**：先确认已绑定目标，再在“诊断与工具”运行链路自检。
- **游戏内看不到**：独占全屏请改成“无边框全屏 / 窗口全屏”。
- **没有主动搭话**：确认宿主支持 conversations 通道，数据源选择 SDK。
- **样式突然恢复**：检查 `data/config/overlay_style.json` 是否可写。
